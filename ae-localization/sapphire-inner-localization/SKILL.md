## 必须保持的边界

1. **界面文字与内部标识分开**：PiPL `eman` 是显示名，`ANMe` 是 matchName；正式入口保持 `S_*`。不翻译 DSL 参数键、枚举 token、表达式或预设标识。不能只改副本文件名就兼容旧工程。
2. **版本与编码分开**：本机标题／PiPL 使用 CP936，Mocha UI 使用 UTF-8；别的环境重新验证。构建接受精确 SHA-256，遇到不匹配停止，不移除版本锁。
3. **批准的范围与可批量生成的范围分开**：词表和候选可批量制作；安装由本次明确范围、共享消费者和证据决定。不是一律一次一个，也不是通过一个就自动推广全部。
4. **别把自动通过写成全部功能通过**：分别记录静态检查、原生添加、默认值、叠加顺序、渲染、预设／编辑器、用户实际使用。间歇故障的一次成功不能确定根因。
5. **保护用户工程**：新建独立诊断工程；存盘后固定项目身份，GUI 操作还需匹配进程和标题。发现用户切换到未保存工程就停止自动操作，不强退，不改变脚本文件／网络安全首选项。
6. **保护已验收消费者**：共享 MediaCore 会影响 AE 和 Premiere；替换前关闭相关宿主、校验备份。被入口引用的 runtime 是依赖，不是垃圾。新增消费者后重新评估旧回退脚本，不能撤销共用核心伤及其他效果。
